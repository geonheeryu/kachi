## 이 저장소에서 지적하지 않는 것

PR 검토 봇이 공통 지침(`.agents/pr-review-common.md`) 뒤에 이어서 받고, PR 전의 `pr-defect-reviewer`도 함께 읽는 파일이다. 범용 관점으로는 결함처럼 보이지만 이 저장소가 정책으로 정한 것을 적는다. 봐야 할 것은 여기에 적지 않는다.

- 하위 호환과 데이터 이행의 누락. 이 저장소는 저장된 데이터를 지우고 다시 만든다.
  - 예: 호환 필드 없이 필드를 지우거나 이름을 바꾼 것, 이행 스크립트 없는 스키마 변경, 옛 형식 문서를 읽는 분기가 없는 것
- 외부 호출에 재시도가 없다는 것. 어댑터는 호출을 한 번 하고 실패를 분류만 한다. 재시도는 저장된 상태(outbox, Kafka offset, 주기 실행)가 한다.
- 계층 의존 방향과 패키지 배치. 아키텍처 테스트(ArchUnit)가 검사한다.
- 마크다운 문서의 내용과 문체. PR 전의 지침 리뷰가 본다.
